Docker Compose Configuration

If you are deploying this application using Docker Compose, you can persist your configuration by mounting the config directory. This ensures your API keys survive container restarts.

Here is a working example of a docker-compose.yml file: 


version: '3.8'

services:
  python_app:
    build:
      context: .
    volumes:
      - .:/app
      # Mount the config directory from your host user to the container user
      # Adjust /home/user/.config/mrp_mongoose to match your local path
      - ~/.config/mrp_mongoose:/home/vscode/.config/mrp_mongoose
    working_dir: /app
    env_file:
      - .env
    ports:
      - "5000:5000"
    command: /usr/local/bin/python src/main.py
Note: The application prioritizes Environment Variables (from .env key) over the configuration file. If you set keys in the Settings page but they don't seem to work, check if you have overrides in your .env file.
